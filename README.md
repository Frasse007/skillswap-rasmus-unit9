# Skill Swap
A site where students tutor each other, either by paying with a credit card or by exchanging expertise in different subject areas.

## Tech Stack

- React 18
- Vite 5
- HTML/CSS

## Getting Started

You need [Node.js](https://nodejs.org/) 18 or later.

```bash
git clone https://github.com/Frasse007/skillswap-rasmus.git
cd skillswap-rasmus
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Scripts

| Command           | What it does                      |
| ----------------- | --------------------------------- |
| `npm run dev`     | Start the development server      |
| `npm run build`   | Build for production into `dist/` |
| `npm run preview` | Preview the production build      |
